SELECTED PROJECT

MONGRI

어린이집·유치원 교사를 위한 디자인 템플릿 브랜드. 여러 교실 자료를 쉽고 빠르게 수정하면서도 하나의 감성적인 스타일로 사용할 수 있도록 브랜드 경험을 설계했습니다.

BX StrategyBrand IdentityLanding Page

Problem

유아교육용 디자인 자료는 많지만 출처마다 스타일이 달라 여러 자료를 함께 사용할 때 교실 전체의 분위기를 통일하기 어렵고, 실제 수정 편의성도 부족할 수 있습니다.

Direction

친근한 캐릭터, 파스텔 컬러, 명확한 정보 영역을 일관되게 적용해 ‘쉽게 수정하면서도 함께 쓰면 하나의 브랜드처럼 보이는’ 템플릿 경험을 목표로 했습니다.

UX 개선 가설
Hero 아래에 추천 템플릿 영역을 추가하면 사용자가 서비스와 상품을 더 빠르게 이해하고 탐색 행동으로 자연스럽게 이어질 것이다.
PROCESS

Research → Strategy → Design

01. 문제 정의교사의 디자인 시간 부족과 자료 간 스타일 불일치를 핵심 문제로 설정했습니다.
02. 포지셔닝유아교육 특화와 편집 편의성을 함께 갖춘 감성 템플릿 브랜드를 지향했습니다.
03. UX 개선랜딩에서 실제 템플릿을 미리 확인할 수 있도록 추천 영역 추가 방향을 도출했습니다.
